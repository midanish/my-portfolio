    Evidence

      How the comparison works

      • What stays the same: the knowledge base (version shown under each answer), the answer model (GLM-4.7-Flash), the answer prompt and settings, a limit of 5 evidence passages, and the citation check that removes any citation the bot was not given.
      • What differs: only retrieval. Bot A searches passages directly. Bot B first navigates the table of contents, the way a reader uses a book’s contents page.
      • Why “STAIR-inspired”: the STAIR paper fine-tunes a model to output a valid section and restricts its output to real section IDs. Bot B uses a general model plus an ID check instead, so it is a simpler prototype, not a reproduction. A fine-tuned version is tested offline in the methodology report.
      • No live scores here: one question is not a test. Quality is measured on a labelled question set; see the methodology report.
      • “Not supported” means the knowledge base does not contain the answer, and the bot is designed to say so instead of guessing.
